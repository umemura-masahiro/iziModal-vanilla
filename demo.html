インストール

npm install izimodal-vanilla

使用例

import iziModal from 'izimodal-vanilla';
import 'izimodal-vanilla/css';

const modal = iziModal('#myModal', {
  title: 'Welcome',
  subtitle: 'This is a modal',
  onOpened: (modal) => {
    console.log('Modal opened!');
  }
});

modal.open();

基本モーダル

これはVanilla JavaScriptで作られたiziModalです。

jQueryは不要で、軽量で高速です！

フルスクリーンモーダル

このモーダルはフルスクリーンで開きます。

右上のボタンでフルスクリーンの切り替えができます。

自動クローズ

このモーダルは3秒後に自動的に閉じます。

プログレスバーで残り時間を確認できます。

カスタムスタイル

ヘッダーの色やアイコンをカスタマイズできます。

様々なオプションで見た目を変更可能です。

トランジション効果

様々なアニメーション効果を選択できます。

開く時と閉じる時で異なるアニメーションも設定可能です。

iframeモーダル

外部コンテンツを読み込めます。
